# Docfy

Docfy is a full-stack document management platform built as a Quality Engineering case study.

The project explores how quality can be designed into a product from its early stages, combining product strategy, test automation, non-functional testing, CI/CD, observability and AI-assisted Quality Engineering.

## Quality Engineering Scope

The project will progressively cover:

- Quality Strategy
- Risk-Based Testing
- Web E2E Automation
- API Testing
- Database Validation
- Performance Testing
- Accessibility
- Usability
- Reliability
- CI/CD and Quality Gates
- Testability
- Observability
- AI-assisted Quality Engineering

## Project Status

🚧 **Currently in Product Foundation phase**

The initial product requirements, business rules and quality principles are being defined before implementation begins.
